[제목]
zz케이던스+ - 케이던스, 평균, 최대, 랩 평균

[소개글]
큰 숫자로 현재 케이던스를 보여주는 데이터 필드입니다. 고른 보조값을 함께 표시하고, 평균보다 높거나 낮으면 색을 바꿔 알려줍니다.
가독성 향상을 위해 TitilliumWeb 폰트를 사용하여 제작되었습니다.
기존 zz케이던스를 새로 만든 앱입니다.

- 케이던스 센서가 필요합니다.

[보조값]
- 평균 케이던스
- 최대 케이던스
- 랩 평균 (앱에서 직접 계산, 0 rpm 코스팅 제외, 랩마다 초기화)
- 없음

[색상 표시]
- 현재 케이던스가 평균(랩 모드는 랩 평균)보다 5% 넘게 높거나 낮으면 색을 바꿉니다.
- 높을 때와 낮을 때 색을 주간/야간 따로 고를 수 있습니다.
- 배경색은 기기 설정(흰색 / 검정)을 따릅니다.

[칸 크기에 맞춘 자동 배치]
- 10칸 레이아웃의 한 칸: 위쪽에 케이던스 아이콘과 보조값, 아래쪽에 현재 케이던스를 크게 표시합니다.
- 가로로 넓은 칸: 위쪽에 zzCadencePlus 제목과 표시 중인 값(AVG / MAX / LAP), 아래쪽에 두 값을 같은 크기로 나란히 표시합니다.
- 다른 Plus 데이터 필드와 같은 글꼴, 같은 크기, 같은 배치를 사용해 함께 쓰면 화면이 일관되게 보입니다.

[지원 기기]
Edge 540 / 550 / 840 / 850 / 1040 / 1050 / 1060

설정은 Garmin Connect IQ 앱 또는 Garmin Express에서 변경할 수 있습니다.
