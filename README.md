# zzCadencePlus

Edge 540 / 840 / 1040 / 550 / 850 / 1050 / 1060 용 케이던스 데이터 필드.
SDK 9.3.0, 타입 체크 Strict(-l 3)로 7개 기종 모두 빌드 확인. 구조와 글자 크기는 zzSpeedPlus와 동일.

## 모드 (설정 "두 번째 값")
0 케이던스만 / 1 평균(averageCadence) / 2 최대(maxCadence) / 3 Lap 평균
- Lap 평균: 앱에서 직접 계산. 타이머 동작 중에만, 0 rpm(코스팅)은 제외, 랩 버튼/리셋 시 초기화.

## 색상 (주간/야간 따로)
- 현재 케이던스가 기준보다 5% 넘게 높으면 '높을 때 색', 5% 넘게 낮으면 '낮을 때 색'
- 기준: 평균/Lap 모드는 표시 중인 값, 케이던스만/최대 모드는 평균 케이던스
- 야간 판단: 데이터 필드 배경이 검정이면 야간 색
- 기본값: 주간 빨강/진한 파랑, 야간 핑크/파랑
- 색상표 인덱스(배포 후 순서 변경 금지): 0 기본, 1 빨강, 2 핑크, 3 자홍, 4 주황, 5 노랑, 6 초록, 7 파랑, 8 진한 파랑, 9 보라

## 화면
- 넓은 칸 타이틀: 칸 폭 300px 미만(540/840, 1040)은 "zzCadence+", 그 외 "zzCadencePlus"
- 칸 폭 > 화면 폭 × 0.75 → 넓은 칸, 그 외 → 10필드 칸
- 10필드 칸 숫자: 540/840 33px·20px, 1040 37·24, 550/850 56·36, 1050/1060 65·41
- 넓은 칸 숫자: 540/840 35px, 1040 42, 550/850 63, 1050/1060 72 (세 자리 값 기준으로 폭 확인)
- 아이콘: cadence.svg를 C10Sub/WideTitle 폰트의 '@' 글리프로 포함

## 폰트
TitilliumWeb (SIL OFL 1.1), Garmin BMFont 형식(그레이스케일 PNG + 채널 정보), 4배 슈퍼샘플링.

## 업로드 전
- manifest.xml application id는 임시 UUID. 기존 zzCadence를 업데이트한다면 기존 앱의 UUID와 개발자 키를 그대로 사용할 것.
